# Simple Tetris

A simple tetris game made entirely in c using the Raylib library.

<img width="537" height="703" alt="image" src="https://github.com/user-attachments/assets/4bdf55b0-ea01-4a5b-8739-ddd278d46dbe" />


### Compiling

Clone the repo and then run the following commands.

```bash
cd simple-tetris && make
```

Finally run the game.

```bash
./tetris
```

### Dependencies

The only dependency is Raylib.
